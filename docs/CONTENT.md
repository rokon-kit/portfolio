#### 1. A Community-Driven Social Volunteering Platform
- **Repository:** [github.com/rokon-rabbi/hands-on-volunteering-platform](https://github.com/rokon-rabbi/hands-on-volunteering-platform)
- **Role:** Full-Stack Lead Engineer
- **Tech Stack:** Spring Boot, React, Tailwind CSS, PostgreSQL, Spring Security, JWT Authentication
- **Problem Space:** Communities frequently face disconnected relief efforts, unstructured volunteer recruitment, and a lack of accountability in community help requests.
- **Engineering Solution:**

  - Relational schema modeling in PostgreSQL ensuring transactional consistency for volunteer sign-ups.
- **The Human Dimension:** Facilitates tangible grassroots aid, connecting individuals in need with local organizers.

#### 2. CourseFlow — University Attendance & Academic Management System
- **Repository:** [github.com/rokon-rabbi/university-project](https://github.com/rokon-rabbi/university-project) (Frontend: TypeScript) & [university-project-server](https://github.com/rokon-rabbi/university-project-server) (Backend)
- **Role:** Full-Stack Software Engineer
- **Tech Stack:** React, TypeScript, Tailwind CSS, Node.js, MySQL
- **Problem Space:** University academic bureaucracy: attendance tracking, course evaluations, and exam clearances are traditionally paper-heavy, error-prone, and bottlenecked at administrative approvals.
- **Engineering Solution:**
  - Multi-tier hierarchical workflow engine: Chairman assigns coordinators; coordinators assign course teachers; teachers manage attendance matrices; students submit anonymous course feedback; provost verifies eligibility and issues digital exam clearances.
  - Type-safe domain models in TypeScript preventing runtime state anomalies across complex approval flows.
- **The Human Dimension:** Replaces weeks of manual physical stamp queues with an intuitive, transparent digital workflow for faculty and thousands of students.

#### 3. Chemistry Calculator — Scientific Desktop Computing Suite
- **Repository:** [github.com/rokon-rabbi/chemistry-calculator](https://github.com/rokon-rabbi/chemistry-calculator)
- **Role:** Software Engineer
- **Tech Stack:** Java, Java Swing, JavaFX
- **Problem Space:** Students and laboratory researchers waste valuable calculation time balancing chemical reactions, calculating stoichiometric ratios, and modeling molarity and titration curves by hand.
- **Engineering Solution:**
  - Algorithmic balancing of chemical equations using matrix balancing and linear system solvers in pure Java.
  - Desktop GUI built with JavaFX / Swing providing immediate error highlighting for invalid chemical formulas and real-time molarity calculation.
- **The Human Dimension:** Enhances STEM educational accessibility and lab safety by reducing manual calculation errors.

#### 4. Scribble — Full-Stack Collaborative Platform
